Здесь собраны все способы установить Istok, проверить, что он работает, обновить или удалить его. Если вы просто хотите начать, хватит однострочного установщика из [Быстрого старта](/docs/ru/getting-started/quick-start).

Istok — один бинарный файл. В нём CLI, MCP-сервер для агента и веб-интерфейс. Сборки есть для Linux (x86-64, ARM64) и macOS (Intel, Apple Silicon). Windows пока не поддерживается.

## Установка скриптом

```sh
curl -fsSL https://get.istok.sh | sh
```

Скрипт определяет систему и архитектуру, скачивает подходящий релиз, сверяет его с SHA-256-суммами релиза и устанавливает `istok` в `~/.local/bin`. `sudo` не нужен.

Если хотите сначала прочитать скрипт:

```sh
curl -fsSL https://get.istok.sh -o install-istok.sh
sh install-istok.sh
```

### Параметры установщика

Параметры передаются после `sh -s --`:

```sh
# Установить в другую директорию (она должна быть в PATH)
curl -fsSL https://get.istok.sh | sh -s -- --install-dir "$HOME/bin"

# Установить конкретный релиз
curl -fsSL https://get.istok.sh | sh -s -- --version v0.2.0

# Показать, что будет сделано, ничего не меняя
curl -fsSL https://get.istok.sh | sh -s -- --dry-run
```

Переменные `ISTOK_INSTALL_DIR` и `ISTOK_VERSION` работают так же, как `--install-dir` и `--version`.

## Установка вручную

Скачайте архив для своей системы со страницы [GitHub Releases](https://github.com/vtimame/istok.sh/releases) и выполните:

```sh
tar -xzf istok_<os>_<arch>.tar.gz
mkdir -p "$HOME/.local/bin"
install -m 0755 istok "$HOME/.local/bin/istok"
```

## Проверка установки

```sh
istok version
istok --help
```

Если оболочка не находит `istok`, значит, директории установки нет в `PATH`.

## Обновление

```sh
istok update
```

Istok покажет текущую и новую версию с описанием изменений и спросит, устанавливать ли обновление. `--check` только проверяет наличие обновления, `--yes` пропускает вопрос. Релизы подписаны, и подпись проверяется до замены бинарника. Что происходит во время обновления, описано в разделе [Обновления и служба веб-интерфейса](/docs/ru/guides/updates-and-service).

## Удаление

1. Если на Linux веб-интерфейс работает как служба, сначала удалите её: `istok ui service uninstall`.
2. Уберите MCP-сервер Istok из настроек агента, например `claude mcp remove istok`.
3. Удалите бинарник: `rm ~/.local/bin/istok` (или из той директории, куда вы его ставили).

Данные при этом остаются на месте. Чтобы удалить и их, удалите директорию данных Istok: `~/.local/share/istok` на Linux (или `$XDG_DATA_HOME/istok`), `~/Library/Application Support/istok` на macOS. В ней лежат база данных, индексы кода и артефакты запусков, если вы не перенесли их через `ISTOK_DATABASE` или `ISTOK_INDEX_ROOT`. Удаление стирает все проекты, задачи, запуски и знания, и отменить его нельзя. Ваши репозитории это не затрагивает.

## Сборка из исходников

Понадобятся Go с включённым cgo (Istok использует SQLite) и pnpm: веб-интерфейс собирается и встраивается в бинарник.

```sh
git clone https://github.com/vtimame/istok.sh.git
cd istok.sh
make install
```

`make install` собирает интерфейс и устанавливает `istok` в `~/.local/bin`. Чтобы собрать в `bin/` без установки, используйте `make build`.

Бинарник, собранный из исходников, не умеет обновлять себя сам. `istok update` сообщит об этом и подскажет, как установить официальный релиз.
