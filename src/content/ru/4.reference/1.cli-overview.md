Команда `istok` даёт прямой доступ к тому же локальному состоянию, с которым ваш агент работает через MCP. С её помощью вы настраиваете Istok, смотрите, что записали агенты, разбираетесь с проблемами и пишете скрипты. Для обычной работы с агентом она не нужна.

## Команды

| Команда            | Назначение                                           |
| ------------------ | ---------------------------------------------------- |
| `istok init`       | Зарегистрировать текущую директорию (или указанный путь) как проект. |
| `istok mcp`        | Запустить MCP-сервер для кодинг-агентов. См. [Инструменты MCP](/docs/ru/reference/mcp). |
| `istok ui`         | Открыть локальный веб-интерфейс или управлять им как сервисом. См. [`istok ui`](/docs/ru/reference/ui). |
| `istok project`    | Смотреть и управлять зарегистрированными проектами. См. [`istok project`](/docs/ru/reference/project). |
| `istok task`       | Смотреть задачи и работать с ними. См. [`istok task`](/docs/ru/reference/task). |
| `istok run`        | Запуски, выполнения команд, артефакты и проверки. См. [`istok run`](/docs/ru/reference/run). |
| `istok context`    | Сохранённый контекст проекта. См. [`istok context`](/docs/ru/reference/context). |
| `istok knowledge`  | Знания проекта. См. [`istok knowledge`](/docs/ru/reference/knowledge). |
| `istok index`      | Посмотреть или перестроить индекс кода. |
| `istok search`     | Искать по индексу кода. |
| `istok graph`      | Исследовать символы и связи между ними. См. [index, search и graph](/docs/ru/reference/index-search-graph). |
| `istok update`     | Проверить и установить новый релиз. |
| `istok completion` | Настроить автодополнение в оболочке. |
| `istok version`    | Показать версию. |

У каждой команды и подкоманды есть своя справка. Именно она — точный список флагов для вашей установленной версии:

```sh
istok --help
istok task --help
istok task show --help
```

## Текущий проект

Большинство команд работают с проектом, в котором находится текущая директория:

```sh
cd ~/work/acme-api
istok task list
```

Если проекты вложены, побеждает ближайший: внутри `apps/web` в монорепозитории команды используют проект `apps/web`, если он там зарегистрирован. См. [Проекты](/docs/ru/how-istok-works/projects).

`istok mcp` следует тому же правилу с одним отличием: каждый процесс MCP-сервера при старте фиксирует корень проекта и исполнителя и не меняет их до конца работы. Поэтому одна глобальная настройка MCP подходит для всех зарегистрированных репозиториев. См. [Инструменты MCP](/docs/ru/reference/mcp#область-проекта).

## Быстрый взгляд на состояние

```sh
istok project show       # текущий проект
istok task list          # открытые задачи
istok run list           # запуски в этом проекте
istok context show       # сохранённый контекст в Markdown
istok index status       # состояние индекса кода
istok search "order not found"
istok graph symbol OrderService
istok graph neighbors OrderService
```

Перестраивать индекс перед поиском не нужно: Istok сам проверяет, актуален ли он.

Если хочется не запрашивать, а просматривать, откройте `istok ui`: там то же состояние по всем проектам. См. [руководство по веб-интерфейсу](/docs/ru/guides/web-ui).

## Вывод JSON

По умолчанию вывод рассчитан на человека. Команды, которые это поддерживают, принимают `--json` и возвращают версионированный ответ для скриптов:

```sh
istok task list --json
```

Есть ли `--json` у команды, видно в её `--help`. См. [Вывод JSON](/docs/ru/reference/json-output).

## База данных

Istok хранит состояние в локальной базе SQLite в пользовательской директории данных. В Linux и macOS файл создаётся с правами `0600`, а его директория по умолчанию — с `0700`, так что другие пользователи на машине не могут его прочитать.

Команды, которые поддерживают другую базу, принимают `--database PATH` или переменную окружения `ISTOK_DATABASE`. Индекс кода и управляемые артефакты хранятся отдельно от базы. См. [Настройка](/docs/ru/reference/configuration).

## Автодополнение в оболочке

Istok генерирует автодополнение для Bash, Fish и Zsh:

```sh
istok completion zsh
```

Чтобы сразу вывести код инициализации:

```sh
istok completion zsh --code
```

Для других оболочек замените `zsh` на `bash` или `fish`.
