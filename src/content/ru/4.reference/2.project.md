`istok project` показывает зарегистрированные проекты и управляет ими. Что такое проект и где хранятся его данные, читайте в разделе [Проекты](/docs/ru/how-istok-works/projects).

## Команды

| Команда                   | Назначение                                            |
| ------------------------- | ----------------------------------------------------- |
| `show [SELECTOR]`         | Показать проект.                                      |
| `list`                    | Показать список зарегистрированных проектов.          |
| `rename NAME`             | Переименовать проект.                                 |
| `rebind SELECTOR [PATH]`  | Привязать проект к другому пути репозитория.          |
| `delete`                  | Переместить проект в корзину, откуда его можно вернуть. |
| `restore SELECTOR [PATH]` | Восстановить удалённый проект.                        |

Без селектора команды берут проект, в котором находится текущая директория; при вложенных проектах побеждает ближайший корень.

## Селекторы

`SELECTOR` может быть:

* ID проекта;
* однозначным префиксом ID;
* именем проекта.

```sh
istok project show acme-api
istok project show 01a00b35
```

Имена не обязаны быть уникальными. Если селектор подходит к нескольким проектам, Istok сообщит о неоднозначности — тогда укажите ID или более длинный префикс.

## Зарегистрировать проект: `istok init`

```sh
cd ~/work/acme-api
istok init
```

Команда регистрирует директорию и строит первый индекс кода. Повторный запуск в директории, которая уже является корнем проекта, вернёт существующий проект. Агенты делают то же самое через MCP-инструмент `project_init`.

Проект можно зарегистрировать внутри директории другого проекта, например приложение внутри монорепозитория:

```sh
cd ~/work/platform
istok init

cd ~/work/platform/apps/web
istok init
```

Оба проекта остаются независимыми. Команды и MCP-серверы, запущенные внутри `apps/web`, используют `web`; во всём остальном `~/work/platform` — `platform`. У двух активных проектов не может быть одинакового корня.

## Показать проект

```sh
istok project show
istok project show acme-api
```

Показывает идентификаторы проекта, его состояние и привязку к репозиторию.

## Список проектов

```sh
istok project list
```

Для каждого проекта выводятся имя, состояние и полный путь к корню репозитория. Удалённые проекты скрыты; чтобы найти проект для восстановления, включите их:

```sh
istok project list --deleted
```

## Переименовать проект

```sh
istok project rename new-name
istok project rename new-name --project acme-api
```

Меняется только имя в Istok — директория и состояние остаются прежними.

## Перепривязать проект

Если репозиторий переехал, перепривяжите существующий проект, а не регистрируйте новый:

```sh
mv ~/work/acme-api ~/projects/acme-api
cd ~/projects/acme-api
istok project rebind acme-api
```

Без `PATH` используется текущая директория. Путь можно передать и явно:

```sh
istok project rebind acme-api /path/to/repository
```

Задачи, контекст, запуски и всё остальное состояние остаются с проектом.

Эта же команда привязывает проект, загруженный с другого устройства, у которого здесь ещё нет папки. См. [Перенос проектов на другое устройство](/docs/ru/guides/another-device).

## Удалить проект

```sh
istok project delete
istok project delete --project acme-api
```

Istok попросит подтверждение. `--yes` пропускает его и обязателен вместе с `--json`, чтобы команда не ждала ввода.

Удаление **не** трогает репозиторий и его файлы. Проект остаётся восстановимым вместе с задачами, запусками и историей, а его директория освобождается, чтобы её мог занять другой проект. Удалить проект можно и в [веб-интерфейсе](/docs/ru/guides/web-ui) — результат тот же.

## Восстановить проект

```sh
istok project restore acme-api
istok project restore acme-api /path/to/repository
```

Без пути Istok использует прежний корень проекта. Если этой директории больше нет, команда завершится ошибкой и попросит путь. Восстановление не сработает, если директорию уже занимает другой активный проект.

## Справка

```sh
istok project show --help
istok project rebind --help
istok project restore --help
```
